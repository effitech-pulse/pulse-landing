# Пульс скважины — лендинг

Самостоятельная статическая страница без БД, ML-кеша и внешних зависимостей.

```sh
python3 build.py
python3 -m http.server 8080 --directory dist
```

Результат: `dist/index.html`. Страница самодостаточна и открывается также из файла.
Утверждённый знак «Поток» встроен из `assets/pulse-symbol.svg`.

Визуальная основа: Figma `km4tIbp3LnMTRrV6yi6Qho`, обзор фонда `3:52`, карточка `3:53`; палитра приложения и знак из brand-kit. Лендинг — самостоятельная композиция, а не копия экрана приложения.

Работают переключение разделов демо, открытие трёх скважин, демонстрация расчёта, мобильное меню, FAQ и скачивание плана пилота. Цифры интерфейса — демонстрационные; реальный расчёт и отправка заявок не выполняются. Горизонт 7–14 суток указан как целевой. Анимации отключаются при `prefers-reduced-motion`.

Исторические PNG и `assets/demo.json` сохранены для совместимости, текущая страница их не использует. Сборка основного проекта: `python3 landing/build.py`; копия для приложения: `frontend/public/landing.html`. При изменении шаблона поддерживать обе версии синхронно. Публикация сайта выполняется отдельно от загрузки исходников в GitLab.


## GitHub CI

Workflow `.github/workflows/ci.yml` запускается на push в `main`, pull request, тег `v*` и вручную. Собирает статический сайт в `dist/` и сохраняет артефакт на 30 дней. Развёртывание и загрузка рабочих данных не включены. Секреты для CI не требуются.
